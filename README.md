# Rehman Construction

React + TypeScript + Tailwind CSS, built as a static website with Vite.

## Setup

Install Node.js 22.12+ and run:

```sh
npm install
npm run dev
```

Open http://localhost:3000.

```sh
npm run lint
npm run build
npm run preview
```

Build output: dist. Preview normally runs on http://localhost:4173.
Commit the package-lock.json generated by npm install; use npm ci for subsequent clean installations.

## Deploy

Vercel: import the repository, select Vite, build with npm run build, output directory dist. No environment variables are needed for static mode. vercel.json records these settings.
https://vite.dev/guide/static-deploy#vercel

Hostinger domain: add the domain to Vercel Project Settings > Domains, then copy the exact records shown there into Hostinger DNS. Preserve email DNS records.
https://vercel.com/docs/domains/set-up-custom-domain

Hostinger hosting: run npm run build and upload the CONTENTS of dist into public_html.

## Feature behavior

The consultant uses the existing preset company answers locally; static mode does not call Gemini. Existing labels and all page text are retained.

The inquiry form opens an email draft and prepares a WhatsApp link. Visitors must finish sending in their email app or WhatsApp. The original sample inquiry is preserved. Static submissions appear only in the current open page and reset on refresh; the list is not a shared company inbox.

The original server.ts and its sample inquiry/company text are preserved. To use that optional development backend, copy .env.example to .env, enable VITE_ENABLE_BACKEND=true, optionally set GEMINI_API_KEY, and run npm run dev:server. Its in-memory inquiry API is a demo, not durable production storage.

All images, CSS colors, themes, and page content are preserved. Image URL strings were converted to imports so Vite includes them in production.
